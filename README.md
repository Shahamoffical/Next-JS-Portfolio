## 🌐 Overview

DevShaham is a **production-ready full-stack portfolio** engineered to showcase high-converting e-commerce builds, custom web applications, and autonomous AI agents. It features a complete **Admin CMS Dashboard** (`/admin`) guarded by **Supabase Authentication**, enabling direct management of portfolio projects, blog articles, leads, and SEO metadata.

### 🌟 Key Highlights

- ⚡ **Sub-1.2s Page Speed Scores**: SSG/SSR hybrid pre-rendering and optimized WebP media delivery.
- 🎨 **Deep Crimson Aesthetic System**: Modern light mode theme featuring `#c00000` accents, glassmorphism, and GSAP micro-interactions.
- 📱 **100% Mobile Responsive**: Customized responsive layouts tested down to 360px mobile viewports.
- 🔢 **Interactive Portfolio Pagination**: 4 projects per page grid view with smooth scroll & category tab resets.
- 🗑️ **Persisted Deletion Sync**: Projects deleted from `/admin` dynamically persist as hidden records in Supabase and filter out across the site.
- 🔒 **Enterprise-Grade Security**: Protected `/admin` routes via Supabase SSR Auth cookies and parameterized database queries.

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ (LTS)
- npm 9+

### Installation & Local Run

```bash
# Clone repository
git clone https://github.com/Shahamoffical/Next-JS-Portfolio.git

# Navigate to project directory
cd Next-JS-Portfolio/Next-JS-Portfolio-main

# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🛡️ Security Architecture

1. **Server-Side Route Guard (`proxy.js`)**: Supabase Auth session token verification protecting `/admin` routes.
2. **Git Security (.gitignore)**: Secret keys & `.env.local` files are strictly excluded from version control.
3. **XSS & SQL Injection Defense**: React JSX automatic escaping paired with Supabase ORM parameterized queries.
4. **TLS/SSL Encryption**: 256-bit encrypted HTTPS transport layer via Vercel Edge CDN.
